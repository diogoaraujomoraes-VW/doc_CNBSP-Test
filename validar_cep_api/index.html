    Validador — CEP API¶

    Verifique se o JSON que você pretende enviar para a API do CEP está de acordo com o manual. A validação roda localmente no seu navegador — nada é enviado a nenhum servidor.

    Como usar:

    1. Cole o JSON na caixa abaixo ou clique em Anexar arquivo (.json ou .txt)
    2. Clique em Validar
    3. Veja o resultado logo abaixo: OK ou a lista de erros com o caminho exato de cada problema
