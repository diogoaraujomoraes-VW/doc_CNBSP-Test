    Validador — CESDI API¶

    Verifique se o JSON que você pretende enviar para a API da CESDI (Separação, Divórcio e Inventário) está de acordo com o manual. A validação roda localmente no seu navegador — nada é enviado a nenhum servidor.

    Como usar:

    1. Cole o JSON na caixa abaixo ou clique em Anexar arquivo (.json ou .txt)
    2. Clique em Validar
    3. Veja o resultado logo abaixo: OK ou a lista de erros com o caminho exato de cada problema

    Para começar rápido, use Gerar modelo de exemplo escolhendo o tipo de ato — os atos de Separação, Divórcio Direto e Conversão já vêm com os campos exigidos pelo IBGE preenchidos.
